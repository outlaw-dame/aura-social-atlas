# Aura Browser

Create a beautiful Native iOS/iPadOS/macOS designed browser that uses iOS 27 Liquid Glass design. I can re-creating and modernizing the Neeva browser it will also be based on Zen browser https://zen-browser.app . Its home page should show the weather and relevant news to the user, the homepage should be like a modern version of Facebook Paper app. It has a built in AI assistant. There's a floating icon that can be used to engage and chat with the assistant. The app should be beautiful, intuitive and butter smooth, the Ai assistant should actually work and be able to answer questions and navigate the browser for the user
