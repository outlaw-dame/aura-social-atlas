Atlas Device Lab

Atlas’s own phone app, built from the repository, running on sample data. Pick a device: the app reads that device’s user agent, screen and posture with its own device profile, then sets Framework7’s navigation and, on wide screens, the desktop-style Discover layout to match. Everything in it is the app’s real code; only Fedizen and Atlas’s server are stood in for.

Sample data: the people, posts, messages and notifications are written for the Lab, and the groups directory is fedizen.net’s public list as captured on 7 November 2026. Likes, saves, joins, follows and posts change the sample data until the page reloads; nothing is sent anywhere.

Verification matrix

Waiting to run

Each row loads a fresh copy of the app at that device’s size and environment, then reads back what Framework7 actually rendered. Every visible control must sit clear of a 24 px zone around any fold, and a folded list pane must end exactly at the fold. Expected values are written out by hand from the layout rules, not computed by the code under test. Safe-area insets are pinned to each device’s published figures where there are any (iPhone) and to none otherwise, so the phone you view the Lab on can’t shift the frame; devices without published figures (iPhone Duo, foldables) still need checking on the real device.
